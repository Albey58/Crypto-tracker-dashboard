# 🪙 Live Crypto Price Tracker Dashboard

A lightweight, interactive web application built with vanilla JavaScript, CSS, and HTML. This dashboard allows users to search for real-time cryptocurrency data using the CoinGecko REST API.

### ✨ Features
* **Real-time API Data:** Fetches live prices and 24-hour price changes using JavaScript `fetch()` and `async/await`.
* **Dynamic DOM Updates:** Automatically renders market data and formatted currency strings.
* **Error Handling:** Features robust input validation and error feedback for nonexistent queries or network issues.
* **Responsive Card UI:** Clean, dark-mode CSS card layout optimized for desktop and mobile screens.

### 🛠️ Built With
* HTML5
* CSS3 (Flexbox, Dark Theme)
* JavaScript ES6+ (DOM Manipulation, Promises, Event Listeners)
* [CoinGecko REST API](https://www.coingecko.com/en/api)
